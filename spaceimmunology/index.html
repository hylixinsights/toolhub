      Explore inferred within-tissue communication

      LIANA (CellPhoneDB method) run per tissue, age and condition. An interaction is gained if significant only after flight and lost if significant only on ground.

      These p-values come from permuting cells, not mice, so groups with more cells have more power. Read gains and losses together with the totals. Significance in only one condition is not a test of a difference between conditions; these categories do not demonstrate functional signaling gain or loss.
